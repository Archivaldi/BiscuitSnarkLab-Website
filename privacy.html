Privacy Policy

This policy covers the public BiscuitSnarkLab website and BiscuitSnarkLab Publisher, the creator-operated application used to produce and publish original animated comedy.

Website visits

This site uses static pages. It has no registration, forms, advertising trackers or analytics scripts. GitHub Pages hosts the site and may process request information under GitHub’s privacy statement. If you email us, we use your address and message to respond.

Account authorization and publishing

The creator can authorize access through Meta OAuth or enter a Meta System User access token locally. The application reads authorized Facebook Page and Instagram account names and identifiers, token validity and permissions, linked account information and publishing eligibility. It uses that information to check access and direct approved posts to the selected destination. When the creator confirms a live post, the application sends the video and its publishing details to Meta and records the result. TikTok is currently simulated in the application.

Local storage and security

Long-lived Meta tokens are stored in macOS Keychain. Temporary Page access tokens stay in memory and app configuration is kept locally. The application uses HTTPS for platform requests. An optional OAuth callback can receive the authorization response through a dedicated HTTPS tunnel. The studio dashboard runs locally. The local SQLite database stores video references, captions, destinations, approvals, job history, timestamps and platform publication identifiers or links when available.

Retention, deletion and revocation

Local project files and publishing history stay on the creator’s system until the creator removes them. Disconnecting an account removes its locally stored token. The creator can also revoke access in the platform’s settings. Revocation stops future use of the revoked credential. Published content and platform records can be managed directly on the platform and are subject to its retention rules.

Third-party services and contact

Meta processes account requests and live posts under its own policies. If the optional Cloudflare tunnel is used, it carries the OAuth callback. GitHub hosts this informational site. For privacy questions, access or deletion requests, email handyart.hire@gmail.com.
